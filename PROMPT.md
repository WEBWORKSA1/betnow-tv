# BetNow.tv — Phase-wise build prompt

Use these prompts in order with any capable AI coding assistant to rebuild, extend or clone this site. Each phase is self-contained and lists acceptance checks.

---

## Phase 0 — Positioning (non-negotiable rules)
> You are building **BetNow.tv**, a free sports **prediction, odds-education, video and free-contest** website. It must be approvable for Google AdSense (publisher `ca-pub-6620975821265271`), so it is **educational and free-to-play only**: no real-money wagering, no sportsbook/casino links, no gambling-operator ads, 18+ notices, and a responsible-gaming page. Do not present any brand called "BetNow". Use the distinct "BN" mark, "BetNow.tv" wordmark and the tagline "Predict · Watch · Learn", and add a non-affiliation trademark/copyright disclosure. Every page starts with a top bar linking the text "Contact, if you are interested in this website/domain name/Sponsorship/Advertisement/Partnership" to `https://web.works/contact`. All forms deliver to one private inbox whose address must never appear in page source (assemble the endpoint at runtime from encoded fragments). Hosting: GitHub Pages free plan, `main` branch, static files only.

**Accept when:** the rules are written into README and the disclaimer page.

## Phase 1 — Architecture & design system
> Create a static site generated by a Python script (`scripts/build.py`) from a shared layout (`scripts/layout.py`), with one CSS file and one dependency-free JS file. Design: dark sports-TV look (navy #0a0f1e, lime #c6ff3d, cyan #38d6ff), Inter + Space Grotesk, 16px base, 1200px container, cards with 16px radius, a light/dark toggle, sticky header, mobile burger menu, a headline ticker and a fully responsive grid (3→2→1 columns). Include the AdSense script in every `<head>`, canonical URLs, Open Graph, JSON-LD (WebSite, Organization, FAQPage, Article), favicon, OG image, manifest, robots.txt, ads.txt and an auto-generated sitemap.xml.

**Accept when:** every page passes a mobile (390px) and desktop (1366px) visual check and has the AdSense code plus the top inquiry bar.

## Phase 2 — Core pages
> Build: Home, Predictions, Tools, Videos, News, Learn (+ articles), Contests, Free Edge Report (lead page), Support (donations), Advertise/Sponsor, Careers, About, Contact, Privacy, Terms, Trademark & Copyright Disclosure, Responsible Gaming, 404. Home sections: hero + trivia widget, today's predictions (6), multi-step lead quiz, tools grid, official video channels, learn guides, live headlines, contests/support/sponsor cards, FAQ.

**Accept when:** all pages link from the header or footer and none is thin (each has a unique title, meta description and real copy).

## Phase 3 — Original content for AdSense approval
> Write at least 9 original long-form guides (500–900 words): odds formats, implied probability & margin, expected value, Poisson soccer models, Elo ratings, home advantage by sport, variance & sample size, advanced stats (xG/EPA/net rating/Corsi/wOBA), free Pick'em strategy. Each guide has worked examples, links into a related tool, a "keep learning" next link, Article schema and an 18+/responsible note where relevant.

**Accept when:** 25+ indexable pages, no copied text, a privacy policy with the Google advertising-cookie disclosures, and an about page with editorial standards.

## Phase 4 — Interactive tools
> Implement in vanilla JS with live updates on input: odds converter (decimal/American/fractional + implied %), margin & fair-probability calculator, expected-value calculator, Poisson score predictor (H/D/A, likeliest score, over 2.5), Elo win probability with home advantage, and a compounding simulator. Each links to its explainer guide.

**Accept when:** default inputs give correct results (2.50 → +150, 3/2, 40%; 2.10/3.40/3.60 → 4.8% margin).

## Phase 5 — Self-updating data (automation)
> Write `scripts/update_data.py` (standard library only) that runs in GitHub Actions every 6 hours. It pulls the next 7 days of fixtures from ESPN's public scoreboard JSON (EPL, LaLiga, UCL, NFL, NBA, NHL, MLB), computes probabilities (soccer: Poisson from live standings with early-season shrinkage and a draw adjustment; US sports: log5 on regressed win % plus a home edge), and builds `data/news.json` from major sports RSS feeds. It never overwrites good data with empty results. The workflow then rebuilds the pages, commits to `main` and deploys to GitHub Pages.

**Accept when:** the Actions run is green and the predictions/news grids populate on the live site.

## Phase 6 — Monetisation & conversion
> **AdSense:** auto ads, ads.txt, cookie consent banner, no ads near clickable picks.
> **Lead generation:** a 3-step quiz (sport → usage → name/email/country + 18+ consent) on Home, Predictions, Tools, Learn and the dedicated Edge page, plus an exit-intent modal (3-day cooldown, mobile 40s timer), a sticky CTA after scroll, B2B partner and custom-model forms, a creator pitch form and an advertiser media-kit form.
> **Donations:** four tiers, a season goal progress bar and a "where the money goes" table (operations, prizes, hiring, marketing). Payment buttons read links from `assets/js/config.js` and fall back to a pledge form.
> **Contests:** free weekly Pick'em (picks saved in localStorage and attached to the entry form), a daily trivia streak, a monthly creator challenge, a countdown, a leaderboard and official rules (no purchase necessary, 18+, void where prohibited).
> **Hiring:** six remote roles plus an application form.

**Accept when:** every form posts successfully and shows a success state, and the inbox address never appears in page source.

## Phase 7 — Launch & growth
> Push to `WEBWORKSA1/betnow-tv`, enable Pages, point the betnow.tv DNS (A records 185.199.108-111.153, `www` CNAME to `webworksa1.github.io`), add the custom domain in Pages settings and enforce HTTPS. Submit the sitemap to Google Search Console, then apply to AdSense with the domain. Growth loop: weekly Edge Report → contest entries → sponsor-funded prizes → shareable leaderboard. Publish 2 new guides a week; add league-specific landing pages (e.g., "/nfl-predictions") once traffic data shows demand.

**Accept when:** the site is live on HTTPS, the sitemap is indexed, the AdSense application is submitted and ads.txt is verified.

Model accuracy tracker (Brier score, calibration chart), team pages, a power-rankings page, a podcast embed hub, multilingual pages (Hindi, French, Spanish), a PWA offline mode, a supporters wall and an API widget for creators.
